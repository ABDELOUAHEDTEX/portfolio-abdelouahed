# Portfolio — Abdelouahed Akabbab

Portfolio bilingue réalisé avec React et TanStack Start.

## Développement

Installez les dépendances avec Bun, puis lancez le serveur de développement :

```sh
bun install
bun run dev
```

Les autres commandes disponibles sont `bun run build`, `bun run test` et
`bun run lint`.
